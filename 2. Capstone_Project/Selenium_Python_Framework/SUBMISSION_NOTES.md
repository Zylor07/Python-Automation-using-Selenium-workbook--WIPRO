# Capstone Assignment 2 — Selenium Python Framework Development

## Objective and implementation

This project automates TutorialsNinja e-commerce login and search with Selenium WebDriver. It implements Page Object Model classes for the two features, separate pytest and unittest test suites, CSV-driven scenarios, INI and environment configuration, explicit waits, and failure screenshots. Both suites generate HTML reports using their own runner. A fresh browser session is created per test, and the optional positive login reads credentials from environment variables.
